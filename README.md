Program 2: Stack and Queue

stack
queue
push()
pop()
top()
front()

Program 3: Count the Steps
Aim
To count the number of times a loop and a nested loop execute.
Concepts Used
for loops
Nested loops
Counter variable
Results
Loop from 1 to 5 runs 5 times.
Loop from 1 to n, where n = 20, runs 20 times.
Nested loops from 1 to 5 execute the PRINT statement 25 times.
Nested loops from 1 to n, where n = 10, execute the PRINT statement 100 times.
Conclusion
These programs demonstrate:
Finding the largest element and sorting an array.
The difference between Stack (LIFO) and Queue (FIFO).
How the number of loop iterations is calculated for single and nested loops.
