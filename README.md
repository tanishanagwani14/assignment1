## Program 1: Find Largest Number and Sort a List

### Aim
To find the largest number in a list and sort the list in ascending order.

### Concepts Used
- Arrays
- Comparison
- for Loops
- Bubble Sort

### Output
```
Largest number: 15
Comparisons made: 4
Sorted list: 2 3 6 8 15
```

## Program 3: Count the Number of Loop Executions

### Aim
To count how many times a loop and nested loops execute.

### Concepts Used
- for Loops
- Nested Loops
- Counter Variable

### Results
- Loop from 1 to 5 executes **5** times.
- Loop from 1 to 20 executes **20** times.
- Nested loops (1 to 5) execute **25** times.
- Nested loops (1 to 10) execute **100** times.
